# ADR-0017: версии полигонального каталога действий

- Статус: принято для R2-Fix.
- Дата: 2026-09-19.

## Контекст

Каталог действий является частью воспроизводимого контракта: номера действий
сохранены в траекториях M6.1, а обученная политика выбирает позиции в порядке
этого каталога. После обнаружения пропущенного контакта на одномерной области
переноса простая замена алгоритма нарушила бы повторное проигрывание и вывод
уже выпущенной модели.

## Решение

- Версия `1` сохраняет прежние действия и их порядок, включая установленный
  дефект одномерной области. Её явно выбирают чтение и генерация наборов данных
  v1/v2, повторное проигрывание, обучение и комплект ONNX с `contracts.action=1`.
- Версия `2` дополняет одномерную допустимую область пересечениями с границами
  NFP и соседними микронными точками. Каждый кандидат проходит прежнюю точную
  проверку допустимости. Обычные базовые запуски и новые вызовы среды по
  умолчанию используют версию `2`.
- Выбор версии выполняется необязательным параметром без изменения форматов
  `polygon_problem`, `polygon_solution`, набора данных и комплекта модели.
- Гибридный запуск существующего комплекта использует версию `1` также для
  резервного базового алгоритма, чтобы сохранить сравнимость результатов.

## Последствия

Существующая модель сохраняет прежние действия и не получает исправление
каталога до выпуска нового комплекта с контрактом версии `2`. Решения базовых
алгоритмов, полученные с версиями `1` и `2`, не следует считать побайтно
совместимыми. Версия каталога не меняет точный валидатор, геометрию детали или
формат задачи; она влияет только на множество и порядок предлагаемых действий.
