# ADR-0008: полигональный набор данных и сравнительное испытание базовых алгоритмов

Статус: принято. Дата: 2026-09-12.

## Контекст

Пробный набор M4 проверяет связность среды, но недостаточен для обучения и не
фиксирует распределение сложности. Черновик M6.1 существовал до декомпозиции A5
и повторно объединял генерацию, сериализацию, кэш, повторное проигрывание и проверку.

## Решение

`aipackaging.polygon_dataset` v2 хранит профили `small`/`medium`, производный начальные значения,
две равномерно масштабированные вариации семьи, инвариантный к повороту хеш
семейства, покрытие, попытку отбраковки, бюджеты и SHA-256 частей набора данных.
Обе вариации принадлежат
одной выборке. Скрытая полочная раскладка проверяется точным `PolygonEnvironment` и
не записывается в обучающие данные.

Каждая принятая задача содержит пять `polygon_trajectory` v1. фактическое время метрики
обнуляются, траектории повторно проигрываются через динамическое пространство
действий C++, а экспертный результат выбирается общим компаратором C++ только
среди полных решений.
Форматы задача, решение и траектория остаются v1; набор данных v1 читается.

Кэш использует общую оболочку A5 с идентификатором задачи и отпечатком всей
конфигурации. Части набора данных записываются общей инфраструктурой
канонического JSONL/gzip.
`polygon_benchmark_report` v1 строится только из замороженных траекторий, различает
равное лучшему и худшее качество и связывается с SHA-256 манифеста.

## Последствия

- многопроцессная обработка и возобновление не меняют опубликованные байты;
- тестовая выборка используется для сравнительного испытания только по явной команде;
- артефакты и кэш не коммитятся;
- M6.1 завершается только после полного прогона 384 задач, проверка и проверка
  сравнительное испытание с зафиксированным манифест SHA-256;
- обучение и ONNX остаются этапами M6.2–M6.3.

384 задачи и 1920 траекторий. SHA-256 канонического манифест:
`747ADE28A858DE2F1D484CDF6C942DF07CB59AF017EEB886F8C18D9105422C44`.
