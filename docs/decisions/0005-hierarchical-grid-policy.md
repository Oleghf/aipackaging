# ADR-0005: Иерархическая клеточная политика M3

- Статус: принято, реализация и эксперимент выполняются
- Дата: 2026-09-10

## Контекст

На задачах M2 постоянный каталог содержит от сотен до 51 тысячи действий.
Плоская классификация всего каталога расходует память на множество позиций
невыбранных деталей и плохо переносится на другой размер задачи. При этом любая
политика обязана выбирать только действие из авторитетной C++ `actionMask`.

Первоначально эталонный GPU-запуск планировался в WSL2. После изменения локальной
политики хоста официальный CUDA PyTorch также проверен непосредственно в Windows;
выбор ОС не меняет контракты seed, checkpoint и evaluation.

## Решение

`HierarchicalGridPolicyV1` один раз кодирует occupancy, формы, признаки деталей
и objective. Actor затем выбирает допустимый экземпляр, его допустимый поворот и
оценивает только позиции этой пары. Вероятность действия факторизуется в сумму
трёх log-probabilities. Critic использует общее представление состояния.

Behavioral cloning использует только expert-траектории train split. PPO
оптимизирует неизменённый reward v1 с `gamma=1`; дополнительное reward shaping и
terminal bonus запрещены. Геометрические шаги выполняются четырьмя spawn worker,
а выбор действий централизован, что сохраняет стабильный порядок результатов.

Экспорт состоит из `encoder.onnx` и `placement-head.onnx`. Метаданные фиксируют
версии контрактов, ограничения, hashes и правило tie-break. Python inference
может вернуть neural solution v2 либо гибридно выбрать лучший результат между
16 rollout политики и `random-left-bottom/64`. Любой результат независимо
проверяется C++-валидатором.

Поддерживаемая среда обучения — Windows либо Ubuntu 24.04 в WSL2 с Python
3.12–3.13 и CUDA. Конкретная ОС записывается в run metadata. Desktop-приложение
не зависит от Python, PyTorch или ONNX Runtime; загрузка ONNX в C++ относится к
M5.

## Последствия

Модель ограничена профилями small/medium: лист до 24×24, 30 экземпляров, extent
детали до 12 и каталог до 65 536 действий. Более крупная задача не считается
геометрически неверной: neural runner отказывает по совместимости, после чего
может использоваться baseline.

M3 считается исследовательски завершённым только после замороженного test-отчёта:
128 валидных полных hybrid-решений, ни одного проигрыша random-64, не менее шести
лексикографических улучшений и хотя бы одного уменьшения `usedLength`.
