# ADR-0003: Контракт клеточного решателя M1

- Статус: принято и реализовано
- Дата: 2026-09-09

## Контекст

Старый автоматический режим связан с GUI-моделью `Board/Figure`, случайным
предварительным порядком и форматом сохранённой сцены. Он непригоден как воспроизводимая
граница для сравнения эвристик и будущей нейросети.

## Решение

Ввести независимую C++20-библиотеку `AIPackaging_Solver`. Задача
`aipackaging.grid_problem` v1 описывает пустой прямоугольный клеточный лист,
связные полимино, количества и четверть-оборотные ориентации. Результат
`aipackaging.grid_solution` v1 хранит размещения, статус, целевая функция, настройки,
счётчики и раздельное время этапов.

Все алгоритмы используют `GridEnvironment`, общий генератор кандидатов и один
валидатор. Реализованы входной первое допустимое место, сортировки по площади и габариту с
размещение снизу слева, случайный поиск с заданным начальным значением и
ограниченный лучевой поиск. Неудачный поиск сохраняет
лучший частичное решение, но такой результат нельзя применять как готовый раскрой.

Полные раскладки сравниваются по минимальному `usedLength`, затем по максимальной
площади дополнительного прямоугольника и минимальной фрагментации. Фрагментация
равна свободной площади занятой по X зоны вне её крупнейшей 4-связной
компоненты. Для частичное решение сначала сравниваются число и площадь размещённых деталей.

## Последствия

решатель и CLI собираются без Qt, а существующий GUI и `packing_scene` v1 остаются
совместимыми. Клеточная среда не моделирует ширина реза, зазор, отверстия, препятствия
или непрерывную геометрию. Эти ограничения не переносятся молча в полигональные
этапы: M2 использует контракт для ML-среды, а M4 заменяет геометрическое
представление при сохранении повторная проверка.
