# План разработки

Оценки рассчитаны на одного разработчика с ИИ-помощником и не являются
обязательством по срокам. Основная платформа приёмки — Windows 11.

## Завершённые этапы

| Этап | Результат |
|---|---|
| M0 | Воспроизводимая сборка, тесты и первый базовый коммит |
| M1 | Клеточное ядро, пять базовых алгоритмов, JSON и CLI |
| M2 | Клеточная обучаемая среда и воспроизводимый набор данных |
| M4 | Полигональная геометрия, NFP, поиск и точный валидатор |
| M5 | Полигональный раскрой в настольном приложении |
| M6.1 | Замороженный полигональный набор из 384 задач и 1920 траекторий |
| M6.2 | Обученная полигональная политика BC/PPO и успешная тестовая оценка |
| M6.3/A7 | Комплект ONNX и получение вывода в C++ без Python |
| A1–A6 | Модульная архитектура, проверки зависимостей и прикладные порты |
| A8 | Вывод унаследованного клеточного настольного редактора |
| R2–R5 | Ревью и устранение подтверждённых дефектов надёжности |
| U1 | Дружелюбное рабочее место технолога версии `0.10.0` |

Клеточный M3 оставлен как замороженная исследовательская ветка: модель,
конвейер BC/PPO и экспорт реализованы, но первоначальный критерий качества
клеточного эксперимента не закрывался. Развитие продукта продолжилось через
полигональную политику M6.2–M6.3.

## M7 — редактируемый документ и импорт DXF

Плановая версия: `0.11.0`. Оценка: 4–6 недель. Статус: не начат.

### M7.1 — модель документа

- добавить независимую от Qt редактируемую модель листа, деталей, колец и
  сегментов;
- использовать стабильные внутренние идентификаторы;
- хранить признаки `dirty`, `valid`, `running` и структурированные диагностики;
- ввести локальный `aipackaging.polygon_draft` v1 для неполной геометрии;
- сохранять строгий `polygon_problem` v1 только после полной проверки;
- добавить атомарное автосохранение и предложение восстановления черновика.

### M7.2 — импорт DXF

Первый выпуск принимает ASCII DXF и поддерживает `LINE`, `LWPOLYLINE`,
`POLYLINE`, дуги по коэффициенту выпуклости `bulge`, `ARC`, `CIRCLE` и базовые кубические нерациональные
`SPLINE`.

Мастер импорта должен:

- определить единицы по `$INSUNITS` или запросить их у пользователя;
- предоставить выбор слоёв;
- показать распознанные цепочки, разрывы и неподдерживаемые сущности;
- не замыкать открытые цепочки молча;
- предложить назначение внешних колец и отверстий;
- позволить задать идентификаторы, количества и повороты;
- создать корректную задачу либо сохранить черновик.

Внутренние типы DXF не выходят из адаптера импорта. `INSERT`, размеры,
штриховки, текст, изображения и 3D-геометрия не входят в первый выпуск.

### Критерий M7

Одинаковый DXF даёт побайтово одинаковый `polygon_problem`. Валидный результат
импорта проходит существующий точный валидатор, а незавершённый документ можно
безопасно сохранить и восстановить как черновик.

## M8 — полигональный редактор

Плановая версия: `0.12.0`. Оценка: 5–7 недель. Статус: не начат.

### M8.1 — команды и история

- создавать, удалять, переименовывать и дублировать типы деталей;
- изменять лист, количества, повороты и производственные параметры;
- создавать внешние кольца и отверстия;
- добавлять, изменять и удалять сегменты;
- перемещать точки и контрольные точки;
- поддержать отмену, повтор и чистую точку последнего сохранения;
- объединять непрерывное перетаскивание в одну команду истории.

Документ нельзя изменять во время поиска. Решатель получает неизменяемый снимок
только после полной проверки.

### M8.2 — инструменты полотна

- выбор сущностей и числовое редактирование координат;
- создание отрезка, дуги и кубической кривой Bézier;
- создание отверстия;
- привязка к сетке, конечным точкам и центрам;
- подсветка направления кольца и геометрических ошибок;
- панель незамкнутых, вырожденных и самопересекающихся контуров;
- подтверждение любых автоматических исправлений пользователем.

Ручное перемещение деталей готовой раскладки, экспорт обратно в DXF и
построение траектории реза в M8 не входят.

## M8.3 — стабилизация редактора

Оценка: 2–3 недели.

- проверить документы с сотнями сегментов и до 100 экземпляров;
- добавить тесты выбора объектов, привязок, истории и восстановления;
- провести ручную приёмку Windows 11 при масштабе 100 %, 150 % и 200 %;
- повторить ревью архитектуры, сохранения и обработки ошибок;
- выполнить полную матрицу C++, Python, Qt, ONNX и санитарных проверок;
- обновить руководство пользователя и поставляемые примеры.

## Итоговый критерий

Технолог без ручного редактирования JSON может создать задачу или импортировать
DXF, исправить контуры и отверстия, настроить производственные параметры,
восстановить незавершённую работу, запустить раскрой и сохранить независимо
проверенное решение.

Форматы существующих задач и решений, замороженный набор M6.1 и комплект модели
M6.3 остаются совместимыми на всех этапах.
