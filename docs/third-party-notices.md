# Компоненты и вопросы распространения

Это перечень локального кандидата, не назначение лицензии проекту.
Публичная публикация заблокирована до решения владельца по коду и модели
и проверки выполнения условий поставляемых компонентов.

| Компонент | Назначение | Условия перед распространением |
|---|---|---|
| AIPackaging | Собственные программа и документация | Лицензия не выбрана |
| Модель M6.3 | Получение вывода ONNX | Условия распространения весов не выбраны |
| Qt 6.9.3 | Окна, рисование, русский перевод | Комплект содержит LGPL/GPL; проверить модули, уведомления, заменяемость DLL и предоставление соответствующих исходников |
| ONNX Runtime 1.29.0 | Выполнение модели | `licenses/onnxruntime/LICENSE` и `ThirdPartyNotices.txt` |
| Clipper2 | Геометрия | `licenses/clipper2/LICENSE`, `Boost Software License 1.0` |
| nlohmann/json 3.12.0 | JSON | `licenses/nlohmann-json/LICENSE.MIT` |
| `Microsoft Visual C++ Runtime` | Среда C++ | Проверить условия распространения установленного комплекта Visual Studio |
| Direct3D/DXC, программный OpenGL | Графические зависимости Qt | Проверить уведомления и условия каждого файла, выбранного `windeployqt` |

Доступные тексты Qt, полные LGPL/GPL, перечень `SPDX` и уведомления библиотек
из установленной документации копируются в `licenses/qt` без изменения. Наличие этих
файлов не доказывает выполнение всех условий. Недостающие уведомления
`Microsoft`, DXC и программного OpenGL, исходники Qt и права на модель остаются
вопросами до публикации. Локальный кандидат не предназначен для передачи
третьим лицам. Python, PyTorch, инструменты сборки и тестовые библиотеки в
ZIP не входят. Состав конкретного архива задаёт `release-manifest.json`.
