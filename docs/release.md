# Локальный кандидат первого выпуска

Текущий этап — R1, версия `1.0.0`. ZIP не означает успешную приёмку или
разрешённую публикацию. Результаты фиксируются в [отчёте R1](reviews/release-candidate-r1.md).

## Сборка

В терминале разработчика Visual Studio x64:

```powershell
$env:VSLANG = '1033'
cmake --preset windows-release-candidate -DQt6_DIR=C:/Qt/6.9.3/msvc2022_64/lib/cmake/Qt6
cmake --build build/windows-release-candidate --parallel 4
python -m unittest discover -s tools/release/tests -v
python tools/release/package_release.py --build-dir build/windows-release-candidate --qt-root C:/Qt/6.9.3/msvc2022_64 --crt-dir "C:/Program Files/Microsoft Visual Studio/18/Community/VC/Redist/MSVC/14.51.36231/x64/Microsoft.VC145.CRT" --output-dir build/releases/r1
```

Перед упаковкой требуется чистое дерево. После последнего коммита повторите
конфигурацию и сборку: `release-build.json`, окно «О программе» и ресурсы
Windows должны относиться к той же ревизии. Упаковщик отклоняет несовпадение,
не заменяет существующий ZIP и не удаляет прежние промежуточные каталоги.
Первая конфигурация получает закреплённые зависимости; для автономной сборки
они должны быть доступны локально. Для упаковки нужна также установленная
документация Qt 6.9.3 с полными текстами лицензий и уведомлениями библиотек.
Комплект модели ожидается в
`artifacts/models/polygon-policy-v1` и проверяется CLI без обучения.

## Состав

Явный перечень включает GUI и CLI Release, библиотеки и плагины Qt, `ONNX Runtime`,
среду MSVC x64, модель, восемь руководств, восемь примеров и
уведомления лицензий. Русский перевод встроен. PDB сохраняются отдельно в
`symbols-<ревизия>`. Тесты, данные обучения, контрольные точки и аудиты не
поставляются. Настройки и восстановление остаются в пользовательских
каталогах Windows, не рядом с программой.

`release-manifest.json` содержит состав и SHA-256, версии и ревизию; сам он
не входит в собственный список хешей. Для ZIP создаётся `.zip.sha256`.
Порядок, время и атрибуты записей фиксированы: одинаковый комплект даёт
одинаковые байты. Это воспроизводимость упаковки, а не компилятора MSVC.

## Ворота приёмки

Проверять распакованный архив на чистой Windows 11 x64: первый запуск и
справку; редактор; три DXF; быстрый и гибридный расчёт с CLI-проверкой;
устаревшее решение; восстановление; отмену работ; испорченную модель;
пути Юникода; перенос каталога; обновление из `0.12.0`; масштабы 100–200 %.
Оконная программная проверка и `QT_SCALE_FACTOR` не заменяют фактический
системный масштаб и физический ввод. Без этой части состояние:
«кандидат собран, приёмка не завершена». P0–P2 блокируют принятие; P3 требует
причины переноса и целевого этапа.

Публикация требует решения владельца по лицензии кода и модели, проверки
[условий компонентов](third-party-notices.md), разрешения отправки и
успешного внешнего CI. Подпись, установщик и автообновление вне R1.
