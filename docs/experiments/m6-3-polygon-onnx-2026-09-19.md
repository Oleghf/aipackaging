# Развёртывание полигональной модели M6.3/A7

## Проверяемый комплект

Выбранная контрольная точка M6.2 экспортирована без изменения весов в два
графа ONNX с набором операций 23. Получение вывода выполняется на CPU через
ONNX Runtime 1.29.0; Python и CUDA настольному приложению не требуются.
Комплект и отчёты находятся в игнорируемом каталоге `artifacts/` и не входят

2.5.3 и ONNX 1.22.0. Для оценки и настольного приложения использован ONNX Runtime 1.29.0
с последовательным исполнением на CPU в одном потоке.

## Совпадение вычислений

На полной проверочной выборке жадные действия PyTorch и ONNX совпали на всех
626 шагах. Максимальное абсолютное расхождение оценок составило
`4.76837158203125e-06` при допустимом пределе `1e-5`. Отдельный общий
синтетический пример проверяет совпадение случайной последовательности,
поворотов и координат в Python и C++ при одинаковом начальном значении.
Каждый итог повторно проверяется точным C++-валидатором.
