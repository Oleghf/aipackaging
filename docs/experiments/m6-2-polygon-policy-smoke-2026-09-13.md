# Пробный запуск полигональной политики M6.2

13 сентября 2026 года на Windows выполнен минимальный цикл BC → PPO на NVIDIA
GeForce RTX 4060. Использовались Python 3.13.14, PyTorch 2.14.0, CUDA 13.0 и
вознаграждение v2.

Запуск завершился штатно, контрольные точки, кэш наблюдений и манифест прошли
проверку SHA-256. Нативная геометрия PPO выполнялась в четырёх рабочих процессах,
а вычисление модели — в одном процессе на CUDA.

На одной проверочной задаче гибридный режим получил полное решение и точно
повторил замороженный результат `random-left-bottom/64`. Нейросетевая часть на
этом коротком запуске его не улучшила. Такая проверка исключает ложную победу,
которая могла бы возникнуть при повторном запуске базового алгоритма с другим
начальным значением.

Этот результат подтверждает работоспособность конвейера, но не является
критерием качества M6.2. Канонические BC/PPO и оценка 64 тестовых задач ещё не
выполнены, поэтому этап остаётся в работе.
