# Канонический эксперимент полигональной политики M6.2

Документ является неизменяемым отчётом завершённого эксперимента. Актуальное
состояние продукта описано в [общей сводке](../current-state.md).

## Конфигурация

Эксперимент выполнен в Windows на NVIDIA GeForce RTX 4060 с Python 3.13.14,
PyTorch `2.14.0+cu130` и CUDA 13.0. Использованы `float32`, начальное значение 42,
вознаграждение v2 и 16 нейросетевых прогонов для режима `best-of`.

- SHA-256 набора данных M6.1:
  `747ade28a858de2f1d484cdf6c942df07cb59af017eeb886f8c18d9105422c44`;
- SHA-256 конфигурации:
  `5465f15e187e56b9a471da5d32378ff8a9ed497ff705b2fd1bb0c53adb1f441a`;
- SHA-256 выбранной контрольной точки:
  `ff15a085836fa9c8e31e28ace360a91bc38dfbca926c2d3d6d332ff007151937`;
- SHA-256 манифеста запуска:
  `239abe18685d82fb7bcda536c0a21697cd6454bb96342d8dc9d7f39095e0884d`.

Общий бюджет BC и PPO составил 28 800 секунд. Процесс был остановлен извне при
достижении этого предела, поэтому запуск зафиксирован со статусом
`budget_exhausted` и неполной историей промежуточных метрик. Веса выбранной
контрольной точки при финализации не изменялись.

Выбрана контрольная точка PPO после обновления 12. Последняя контрольная точка
продолжения относится к обновлению 25 и не улучшила проверочный результат.

## Итог

Критерий M6.2 выполнен полностью:

- 64 из 64 гибридных решений являются полными и корректными;
- поражений относительно `random-left-bottom/64` нет;
- получено 14 строгих побед при требовании не менее шести;
- `usedLength` улучшен в восьми задачах при требовании хотя бы одной.

M6.2 завершён. Контрольная точка остаётся локальным артефактом и не подключена
к настольному приложению. Экспорт ONNX и получение вывода в C++ относятся к
M6.3.
