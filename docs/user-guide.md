# Руководство пользователя настольного приложения

## Начало работы

После запуска открывается начальная страница. На ней можно выбрать недавнюю
задачу, один из трёх поставляемых примеров или нажать «Открыть задачу…».
Приложение принимает строгий файл `aipackaging.polygon_problem` версии 1 и
черновик `aipackaging.polygon_draft` версии 1 с расширением `.aipdraft.json`.

Недоступный недавний файл остаётся видимым с пояснением. Его можно выбрать и
убрать из списка. Импорт DXF доступен на начальной странице и в меню «Файл».
Создание задачи и изменение геометрии появятся в M8, поэтому команда создания
пока недоступна.

Если предыдущая работа оставила автоматический черновик, на начальной странице
появляется карточка со временем и источником. Команда «Восстановить» открывает
его как отдельный несохранённый документ. Команда «Удалить» безвозвратно
удаляет только автоматический файл. Повреждённый черновик восстановить нельзя,
но его можно удалить.

Если исходный файл изменился после автосохранения, приложение предупреждает об
этом. Восстановление остаётся доступным, однако документ потребуется сохранить
по новому пути.

## Импорт DXF

Команда «Импортировать DXF…» открывает мастер из пяти шагов. Исходный файл
только читается и никогда не перезаписывается.

1. Проверьте единицу длины. Если `$INSUNITS` отсутствует, равен нулю или
   неизвестен, выберите единицу явно. Допуск соединения концов по умолчанию
   равен 0,01 мм.
2. Выберите слои. Неподдерживаемые сущности выбранного слоя требуется либо
   исключить вместе со слоем, либо явно разрешить пропустить.
3. Проверьте цепочки. Почти совпадающие концы объединяются только после отметки;
   открытые цепочки не замыкаются автоматически. Подтвердите внешние кольца и
   отверстия.
4. Задайте идентификаторы, количества и разрешённые повороты деталей. Равные
   контуры объединяются только при включённом подтверждении группировки.
5. Проверьте размеры листа и производственные параметры. Начальные размеры
   вычисляются по габаритам выбранных деталей и округляются вверх до миллиметра.

Поддерживаются `LINE`, `LWPOLYLINE`, двумерный `POLYLINE`, дуги полилиний,
`ARC`, `CIRCLE` и базовый кубический нерациональный `SPLINE`. `INSERT`, размеры,
штриховки, текст, изображения и трёхмерная геометрия показываются как
неподдерживаемые.

Полностью корректный результат проходит точный полигональный валидатор и
принимается как грязная задача. `Ctrl+S` предлагает новый файл
`polygon_problem`; путь DXF не используется для сохранения. Документ с ошибками
можно принять только как черновик `.aipdraft.json`, чтобы исправить его в
будущем редакторе. Отмена или ошибка сохраняет прежние документ, сцену и
решение.

## Выполнение раскроя

После открытия задачи слева показываются лист и типы деталей, в центре — полотно,
справа — способы запуска. Доступны режимы:

- «Быстрый» для короткого детерминированного расчёта;
- «Качественный» для ограниченного лучевого поиска;
- «Нейросетевой» для выбора лучшего из 16 прогонов модели;
- «Рекомендуемый гибридный» для сравнения модели с надёжным базовым алгоритмом.

Нейросетевые режимы доступны только после успешной проверки комплекта модели.
Выбор модели выполняется в фоне; проверку можно отменить. Если новая модель
повреждена, ранее проверенная модель продолжает работать.

Точные алгоритмы, начальное значение и бюджеты находятся в «Расширенных
настройках». Их изменение переводит запуск в «Пользовательские настройки».

Во время поиска открытие другой задачи и изменение параметров заблокированы.
Команда «Отменить» остаётся доступной. Нижняя область показывает этап, ход
выполнения, предупреждения и подробные метрики.

Некорректный черновик открывается вместе со списком диагностик. Его можно снова
сохранить как черновик, но запуск раскроя и запись в строгий
`polygon_problem` заблокированы до устранения ошибок в будущем редакторе.

## Просмотр и сохранение

Колесо мыши меняет масштаб, перетаскивание перемещает камеру, а команда «Вписать
лист» возвращает общий вид. Строка состояния показывает координаты курсора в
миллиметрах. Щелчок по размещённой детали показывает её тип, экземпляр, габариты
и поворот.

Полное решение отмечается явно. Для частичного результата показываются причина
завершения и неразмещённые экземпляры. Сохранить можно только результат, который
повторно принят точным валидатором.

`Ctrl+S` сохраняет исходный документ. Загруженная корректная задача
записывается обратно как `polygon_problem`; пользовательский черновик — как
`.aipdraft.json`. Для восстановленного или некорректного документа приложение
предлагает новый путь черновика. Проверенное решение сохраняется отдельно через
`Ctrl+Shift+S`.

Перед открытием другого файла или закрытием грязного документа приложение
предлагает сохранить изменения, отбросить их либо отменить действие.
Автоматическое сохранение выполняется через две секунды после последнего
изменения и не заменяет пользовательский файл.

Размер окна, положение панелей, последние задачи, последний каталог и путь к
проверенной модели сохраняются между запусками. Ошибка открытия новой задачи
или модели не удаляет предыдущую корректную сцену.

Основные сочетания клавиш:

- `Ctrl+O` — открыть задачу;
- `Ctrl+S` — сохранить документ;
- `Ctrl+Shift+S` — сохранить проверенное решение;
- `Ctrl+Enter` — запустить раскрой;
- `Esc` — отменить расчёт;
- `F` — вписать лист в полотно.
