## Архитектурные решения

ADR находятся в каталоге [`decisions`](decisions/). Они фиксируют контекст и
причины решения, поэтому не переписываются как описание текущей системы. Если
решение заменено, его статус содержит ссылку на последующий ADR.

Основные действующие решения:

- [ADR-0001](decisions/0001-hybrid-neural-solver.md) — разделение нейросетевой
  стратегии и точной геометрии;
- [ADR-0002](decisions/0002-valuable-remnant-objective.md) — ценность правого
  повторно используемого остатка;
- [ADR-0006](decisions/0006-polygon-nesting-contract.md) — полигональная
  геометрия и производственные расстояния;
- [ADR-0014](decisions/0014-polygon-application-ports.md) — прикладные порты;
- [ADR-0015](decisions/0015-polygon-onnx-deployment.md) — комплект ONNX;
- [ADR-0016](decisions/0016-retire-legacy-desktop.md) — завершение поддержки
  клеточного настольного редактора;
- [ADR-0017](decisions/0017-versioned-polygon-action-catalog.md) — версии
  каталога действий;
- [ADR-0018](decisions/0018-active-polygon-document-lifecycle.md) — жизненный
  цикл активного документа;
- [ADR-0019](decisions/0019-friendly-desktop-workspace.md) — рабочее место U1.
