# Раскрой и модель

| Режим | Назначение |
|---|---|
| Быстрый | Базовое размещение по площади, до 30 секунд |
| Качественный | Лучевой поиск: ширина 32, до 50 000 состояний и 30 секунд |
| Нейросетевой | 16 прогонов проверенной политики, до 300 секунд |
| Рекомендуемый гибридный | Сравнение нейросетевых прогонов с 64 случайными базовыми попытками, до 300 секунд |

Экспертная область содержит алгоритмы, начальное значение и бюджеты.
Изменение экспертных параметров переводит режим в пользовательские настройки.

Комплектная модель проверяется при первом запуске из `models/polygon-policy-v1`.
До завершения проверки доступны базовые режимы. Повреждённая модель не принимается.
Команда «Использовать комплектную модель» запускает повторную проверку.

Явно выбранная внешняя модель имеет приоритет. При ошибке она не подменяется молча;
можно выбрать комплектную. Если другая корректная модель уже загружена, отказ замены
не уничтожает её. «Забыть модель» отключает автоматический выбор до нового подключения.
Перенос папки приложения не должен ломать путь к комплектной модели.
Сохранённый пользовательский режим не сбрасывается при следующем запуске.

Полный результат означает размещение всех экземпляров. При ограничении времени,
бюджета или отмене может быть доступен только частичный результат.
Смотрите причину завершения и список неразмещённых экземпляров.

Разрешены только повороты 0°, 90°, 180°, 270°, без зеркального отражения.
Используется один прямоугольный лист. Детали внутри отверстий не размещаются.
`sheetMargin` задаёт отступ листа, `partSpacing` — междетальный зазор.
`kerf` сохраняется как технологическое поле, но не меняет размещение.
Программа не строит траектории реза и не гарантирует глобально оптимальное решение.
