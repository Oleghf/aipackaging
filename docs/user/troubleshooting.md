# Решение проблем

| Ситуация | Что сделать |
|---|---|
| Программа не запускается, отсутствует DLL | Распаковать полный проверенный архив; не скачивать случайные DLL из интернета |
| Не открывается справка | Проверить наличие каталога `docs/user` рядом с программой |
| Модель не подключена | Дождаться проверки; изучить причину ошибки; выбрать «Использовать комплектную модель» |
| После замены модель не работает | Не смешивать файлы разных комплектов; вернуть целиком проверенный каталог |
| Раскрой недоступен | Открыть вкладку «Проблемы», исправить локальную и точную геометрию |
| DXF не принимается | Проверить текстовый формат, единицы, нормаль, поддерживаемые сущности и целостность файла |
| Сохранение не удалось | Выбрать доступный каталог и свободное место; не считать сообщение об ошибке успешной записью |
| Решение устарело | Повторить расчёт после изменения исходного документа |
| Отмена текста не отменяет геометрию | Перевести фокус на полотно или дерево, затем нажать `Ctrl+Z` |
| Кнопки не видны | Проверить размер окна и прокрутку; сообщить разрешение и системный масштаб Windows |

Для сообщения об ошибке укажите версию и ревизию из «О программе», Windows,
масштаб интерфейса, шаги воспроизведения, ожидаемый и фактический результат.
Приложите минимальный обезличенный документ и текст сообщения об ошибке.
Не передавайте производственные чертежи, персональные пути и секреты без разрешения владельца.

Ручная проверка и приёмка на чистой Windows учитываются отдельно от автоматических тестов.
Условия публичного распространения проекта ещё не определены; текущая поставка —
локальный кандидат.
