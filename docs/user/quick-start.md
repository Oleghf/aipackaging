# Первый раскрой

1. Скопируйте `examples/polygon/problem-small.json` из поставки в свой рабочий каталог.
2. Запустите `AIPackaging.exe`, выберите «Открыть задачу» или нажмите `Ctrl+O`.
3. Проверьте размеры листа, количества деталей, повороты, отступ и междетальный зазор.
   Координаты и расстояния задаются в миллиметрах.
4. На вкладке раскроя выберите «Быстрый» и запустите расчёт кнопкой или `Ctrl+Enter`.
5. Проверьте число размещённых экземпляров. Частичный результат не означает размещение всех деталей.
6. Сохраните решение через «Сохранить решение» или `Ctrl+Shift+S`.
7. Сохранение исходной задачи — отдельная команда `Ctrl+S`. Откройте её снова,
   чтобы убедиться, что вы сохранили именно документ, а не только раскладку.

Для новой задачи выберите «Создать задачу», задайте идентификатор и размеры листа,
добавьте деталь в редакторе и постройте замкнутый внешний контур.
Пока документ некорректен, он сохраняется как черновик, но не запускается на раскрой.

После проверки комплектной модели можно выбрать «Рекомендуемый гибридный».
Она не гарантирует лучшую раскладку для любой задачи; каждый результат проверяется геометрически.
