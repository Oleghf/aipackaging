# Документ, решение и восстановление

- Задача `polygon_problem` версии 1 содержит проверенную исходную геометрию и параметры.
- Черновик `.aipdraft.json` сохраняет незавершённый документ, но не историю отмен.
- Решение `polygon_solution` содержит результат раскроя и сохраняется отдельно.

`Ctrl+S` сохраняет исходный документ согласно его состоянию и источнику.
«Сохранить задачу как…» записывает корректную задачу по новому пути, в том числе
после исправления черновика. `Ctrl+Shift+S` сохраняет только актуальное проверенное решение.
Перед заменой грязного документа предлагаются «Сохранить / Отбросить / Отмена».

Автосохранение выполняется после двух секунд без изменений. Оно не заменяет
пользовательский файл и не делает документ сохранённым.
При аварии гарантированно доступна только последняя завершённая запись.
Следующий запуск показывает карточку восстановления. Восстановленный документ
остаётся изменённым; проверьте его и сохраните под подходящим именем.

Если источник изменился, восстановление показывает предупреждение и требует нового пути.
После успешного сохранения очищается только принадлежащий документу автоматический черновик.
Ошибка записи или удаления восстановления должна быть показана, а не скрыта.

До обновления и важных изменений делайте отдельные резервные копии пользовательских файлов.
Не удаляйте вручную автоматический черновик, пока не решили, нужен ли он.
