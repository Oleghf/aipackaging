# AIPackaging 1.0.0 — руководство

Локальный кандидат для Windows 11 x64. Это редактор исходных деталей и расчёт раскладки,
а не система управления станком: траектории реза и управляющие программы не создаются.

- [Импорт DXF](dxf.md)
- [Сохранение и восстановление](documents.md)

- [Решение проблем](troubleshooting.md)
