# Установка, обновление и откат

## Требования и запуск

Поддерживаемая платформа — Windows 11 x64. Распакуйте ZIP полностью в доступный каталог.
Запускайте `AIPackaging.exe`; устанавливать Qt, Python или Visual Studio не требуется.
Для командной строки используйте `AIPackaging_Cli.exe`. Не запускайте приложение прямо из архиватора.

Контрольная сумма архива находится в соседнем файле `.sha256`. Сравните её командой:

```powershell
Get-FileHash .\AIPackaging-1.0.0-windows-x64.zip -Algorithm SHA256
```

Совпадение подтверждает целостность файла относительно полученной суммы, но не заменяет
проверку источника. Кандидат не подписан цифровой подписью. Не отключайте защиту Windows;
используйте только полученный от доверенного источника комплект.

## Где хранятся файлы

Приложение не требует установки, но не является полностью переносимым профилем.
Документы сохраняются по выбранным вами путям. Настройки остаются в пользовательском
профиле Windows (`QSettings`, организация и приложение `AIPackaging`).
Черновик восстановления расположен в пользовательском каталоге
`AppLocalDataLocation/autosave/active.aipdraft.json`; он не находится внутри ZIP.

Модель ищется в `models/polygon-policy-v1` относительно программы. Справка — в
`docs/user`, примеры — в `examples`. Эти каталоги переносите вместе с программой.
Работа не требует сети. Не храните собственные документы поверх поставляемых примеров:
сначала скопируйте пример в свой рабочий каталог.

## Обновление с 0.12.0

1. Сохраните документ и закройте старое приложение. Сделайте резервные копии документов.
2. Не удаляйте пользовательские настройки и автоматический черновик.
3. Распакуйте новую версию в другой каталог, не поверх работающей программы.
4. Откройте копию прежней задачи; проверьте детали, параметры и сохранение.
5. Если есть восстановительный черновик, сначала решите, нужно ли его восстановить.

Форматы задач, решений и черновиков версии 1 не изменены.
Комплектная модель переносится вместе с новой программой; путь явно выбранной внешней
модели сохраняется. Для отката закройте новую версию и запустите сохранённую старую.
Не запускайте обе версии одновременно с одним профилем и автоматическим черновиком.

Удаление распакованной папки не удаляет ваши документы, настройки и восстановление.
