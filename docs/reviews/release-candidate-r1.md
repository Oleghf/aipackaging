# R1 — подготовка локального кандидата

Дата: 8 октября 2026 года. Исходная точка: `main`, `0b5092c`, чистое дерево.
Версия кандидата — `1.0.0`. Статус: **кандидат собран, приёмка не завершена**.
Публикация и отправка изменений не выполняются.

## Ограничение GUI-A1-01

В штатной Windows-пробе Qt 6.9.3, `QWindows11Style`, мастер `AeroStyle`
сохраняет доступную кнопку «Далее» при `QT_SCALE_FACTOR=1/1.5/2`.
Переходы пяти страниц вперёд и назад проверяются событиями мыши Qt.
Это оконная автоматизация, не ручной ввод и не смена системного масштаба.
В `offscreen` тот же стандартный контейнер остаётся неправильно обрезанным.
Оформление продукта не изменялось. Исходная проба сохраняется командой
`python tools/run_checks.py gui-environment-diagnostic` с ненулевым результатом.
В основной приёмке этот сценарий выполняется на платформе `windows`,
остальные — в `offscreen`; отказ не превращён в ожидаемый успех.

Журналы: `build/r1-wizard-windows-1.log`, `build/r1-wizard-windows-1.5.log`,
`build/r1-wizard-windows-2.log`, расширенная проверка — `build/r1-wizard-check.log`.

## Локальная регрессия

Qt 6.9.3, MSVC 19.51, CMake 4.3.2, Python 3.13.14,
ONNX Runtime 1.29.0. Нативная Python-привязка пересобрана до запуска тестов;
версия и отпечаток совпали. Старый каталог `build/pytest-temp` недоступен

проба GUI — MSVC Release, `offscreen`, два прогрева и 30 измерений.

сравнение относительного порога с исходной M8.2 на той же ревизии среды
не повторялось; это отдельное ограничение измерений.

Сборка и упаковка выполнены при чистом рабочем дереве. Последующий коммит
отчёта не меняет код и состав кандидата.

- архив: `build/releases/r1/AIPackaging-1.0.0-windows-x64.zip`;
- размер: 38 876 469 байт;
- SHA-256: `8fba1b91637df388a6d4680d3021891ab96227acf37b1fbc33e020386727a100`;
- 95 файлов содержимого и манифест; PDB сохранены отдельно;
- исходный промежуточный каталог: `build/releases/r1/candidate-3y_00q3d`;
- повторная упаковка дала побайтово тот же ZIP;
- ресурсы Windows содержат `1.0.0`, подсистема GUI подтверждена через `dumpbin`;
- проверены хеши всех распакованных файлов и зависимости 22 файлов PE.

Архив распакован в `build/releases/r1/проверка 候補`, затем тестовая копия
перенесена в `build/releases/r1/перенесённый 候補`. Из другого рабочего
каталога при `PATH=C:\Windows\System32` поставляемый CLI успешно выполнил
`validate-model`, быстрый расчёт и `hybrid` с 16 прогонами и 64 случайными
попытками. Оба результата имеют `status=solved` и прошли `validate`.
Выходные файлы также содержат кириллицу и иероглифы в имени. Исходные файлы
модели не изменялись. Журналы — `build/releases/r1/working-directory/`.
Проверка таблиц PE и ограниченного `PATH` не доказывает автономность GUI
на чистой машине: динамическая загрузка плагинов требует оконного сценария.
