# R1 — подготовка локального кандидата

Дата: 8 октября 2026 года. Исходная точка: `main`, `0b5092c`, чистое дерево.
Версия кандидата — `1.0.0`. Статус: работа и приёмка не завершены.
Публикация и отправка изменений не выполняются.

## Ограничение GUI-A1-01

В штатной Windows-пробе Qt 6.9.3, `QWindows11Style`, мастер `AeroStyle`
сохраняет доступную кнопку «Далее» при `QT_SCALE_FACTOR=1/1.5/2`.
Переходы пяти страниц вперёд и назад проверяются событиями мыши Qt.
Это оконная автоматизация, не ручной ввод и не смена системного масштаба.
В `offscreen` тот же стандартный контейнер остаётся неправильно обрезанным.
Оформление продукта не изменялось. Исходная проба сохраняется командой
`python tools/run_checks.py gui-environment-diagnostic` с ненулевым результатом.
В основной приёмке этот сценарий выполняется на платформе `windows`,
остальные — в `offscreen`; отказ не превращён в ожидаемый успех.

Журналы: `build/r1-wizard-windows-1.log`, `build/r1-wizard-windows-1.5.log`,
`build/r1-wizard-windows-2.log`, расширенная проверка — `build/r1-wizard-check.log`.

## Локальная регрессия

Среда: Windows 11 `10.0.26200`, `AMD Ryzen 5 5600`, 16 ГиБ ОЗУ,
Qt 6.9.3, MSVC 19.51, CMake 4.3.2, Python 3.13.14,
ONNX Runtime 1.29.0. Нативная Python-привязка пересобрана до запуска тестов;
версия и отпечаток совпали. Старый каталог `build/pytest-temp` недоступен
для удаления, поэтому полный повтор использовал `--basetemp=build/r1-pytest-temp`.
Первый отказ подготовки окружения не считается дефектом Python-продукта.

Манифест M6.1, все шесть частей набора, выбранная контрольная точка и
идентичность модели совпали с каноническими хешами. Обучение канонической
модели, полная генерация, оценка тестовой выборки и 1920 траекторий не
запускались. Малые обучающие тесты входят в штатный pytest.

Проба редактора: `editor-500` — 35 848 192 байта при живой истории;
`editor-1000` — 65 503 232 байта. Для 1000 сегментов `p95` проверки 0,8804 мс,
истории 0,4837 мс. Значения относятся к программной пробе, не физическому
отображению. Журналы: `r1-editor-performance.log`, `r1-gui-performance.log`.
Независимая проба ядра использует существующую Release-сборку MinGW;
проба GUI — MSVC Release, `offscreen`, два прогрева и 30 измерений.
Для 1000 сегментов: отображение `p95` 75,935 мс, поиск 10,122 мс,
привязка 0,237 мс, отрисовка 7,078 мс, предварительный просмотр 18,835 мс,
редакция 55,887 мс, отмена/повтор 36,875/36,141 мс, постановка записи 0,152 мс,
завершение записи 73,645 мс. Все абсолютные пределы соблюдены. Прямое
сравнение относительного порога с исходной M8.2 на той же ревизии среды
не повторялось; это отдельное ограничение измерений.

## Оставшиеся ворота

До получения результатов чистой Windows статус не может быть «принят».
Обязательны 12 сценариев [выпускной матрицы](../release.md#ворота-приёмки).
Версии, состав, хеш архива и фактические команды будут зафиксированы после
сборки. Внешний CI без публикации не запускался; лицензия собственного
проекта и модели остаётся решением владельца.
