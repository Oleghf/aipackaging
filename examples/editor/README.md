# Примеры редактора

Файлы в этом каталоге предназначены для ручной проверки редактора и не входят
в эталоны CLI.

- `demo-open-path.aipdraft.json` — незавершённый открытый контур с кубической
  кривой Bézier; его можно восстановить, исправить и сохранить как строгую
  задачу после замыкания.
- `demo-part-with-hole.aipdraft.json` — завершённая прямоугольная деталь с
  прямоугольным отверстием.
