# AIPackaging

AIPackaging `1.0.0` — локальный кандидат редактора полигональных деталей и системы
двумерного раскроя на прямоугольном листе для Windows 11 x64.
Публичный выпуск и лицензия проекта пока не утверждены.

## Запуск готового комплекта

1. Полностью распакуйте `AIPackaging-1.0.0-windows-x64.zip`.
2. Запустите `AIPackaging.exe`. Python, Qt и Visual Studio пользователю не нужны.
3. Дождитесь фоновой проверки комплектной модели либо используйте базовый режим.
4. Скопируйте пример из `examples/polygon` в свой каталог и откройте его.
5. Выберите «Быстрый», выполните раскрой и сохраните решение через `Ctrl+Shift+S`.
   Исходный документ сохраняется отдельно через `Ctrl+S`.

В ZIP входят CLI, ONNX-модель, примеры и автономная справка (`F1`).

## Возможности и ограничения

- создание задачи, числовое и интерактивное редактирование линий, дуг, Bézier и отверстий;
- импорт поддерживаемого подмножества текстового DXF с явными подтверждениями;
- отмена/повтор, строгие черновики, автоматическое сохранение и восстановление;
- пять базовых алгоритмов, ONNX-политика и гибридный режим;
- независимая геометрическая проверка полного или частичного результата;
- один прямоугольный лист, миллиметры, повороты 0/90/180/270°, без отражений;
- `sheetMargin` и `partSpacing` влияют на раскрой; `kerf` пока только сохраняется;
- нет размещения в отверстиях, экспорта DXF, траекторий реза и управляющих программ станка.

Программа не гарантирует глобально оптимальную раскладку и не заменяет
производственную проверку технологом. Готовая раскладка доступна для просмотра;
редактируется исходная задача.

```powershell
cmake --preset windows-release-candidate -DQt6_DIR=C:/Qt/6.9.3/msvc2022_64/lib/cmake/Qt6
cmake --build build/windows-release-candidate --parallel 4
```

Команды выполняются из среды MSVC. CMake получает закреплённые зависимости;
для сборки нужен Python, но он не включается в настольную поставку.

Клеточный контур CLI/Python сохраняется для воспроизводимости исследований.
Данные, обученные веса, контрольные точки и локальные результаты не входят в Git.
Лицензия собственного проекта не выбрана; публичное распространение не разрешается
самим наличием этого репозитория или локального ZIP.
